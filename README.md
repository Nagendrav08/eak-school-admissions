# EAK International School — Admissions Landing Page

A responsive admissions landing page for EAK International School's fictional 2027–28 academic session, built as a frontend hiring assignment.

## Features

- School introduction and admissions hero section
- Why Choose Us and academic programs
- School highlights and facilities
- Admission process and important dates
- Required documents checklist
- Fee structure preview
- Parent testimonials
- Interactive FAQ accordion
- Frontend-only enquiry form with validation and confirmation
- Responsive layouts for desktop, tablet, and mobile

## Technologies Used

- React
- Vite
- JavaScript (JSX)
- CSS3
- HTML5

## Prerequisites

Install Node.js and npm before running the project.

## Installation and Setup

1. Clone or download the project.
2. Open a terminal in the project directory.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL printed in the terminal.

## Production Build

Run:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```

## Notes

- This project is a frontend demonstration. The enquiry form does not send data to a backend or database.
- Sample fees, dates, statistics, and testimonials are fictional.
- The hero image and Google Fonts are loaded from external URLs and require an internet connection.
